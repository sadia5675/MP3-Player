# MP3-Player

Dieses Projekt ist ein MP3-Player-Projekt, das im Rahmen des Fachs "Entwicklung Interaktiver Benutzeroberflächen" an der Hochschule RheinMain entwickelt wurde.

## Technologien

Dieses Projekt verwendet:
- **Java**
- **JavaFX**
- **CSS**
